# Лабораторная работа №2 (краткий отчёт)

## Суть 
Выражение `x² - x² + 4x - 5x + x + x` математически равно `x`.

## Поведение компиляторов
- **C++ (g++ -O2)**: оптимизирует выражение на этапе компиляции, заменяя на `x`
- **Python (3.x)**: интерпретатор честно выполняет все операции на каждой итерации

## Результаты (100000000 итераций)


| C++ | ~0 ms | Нет (оптимизировано) |
| Python | ~20 000 ms | Да (100000000 операций) |

## Вывод
C++ быстрее не только из-за компиляции, но и из-за **агрессивной оптимизации** кода на этапе сборки. Python выполняет каждую операцию "как написано". Но даже если бы выражение было бы сложнее, в силу того, что интерпретатору необходимо ещё некоторое время (на каждую строчку) для преобразования исходного кода в машинный, С++ выигрывал бы в производительности.
